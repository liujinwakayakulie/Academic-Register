## 这是什么？

一个用于**去除AI生成文本的"AI味"**、将其润色为规范**学术语域**的提示词技能。

## 为什么需要它？

大语言模型生成的文本常有以下问题：

- 修饰词堆砌，形容词泛滥
- 情绪化、夸张的表达
- 论断过强，与证据强度不匹配
- 口语化或非正式措辞

学术写作则要求四个品质：**客观、正式、准确、审慎**。

## 核心原则

改编自 [桑德兰大学学术写作指南](https://libraryguides.sunderland.ac.uk/academic-writing/academic-register)。每次修订均从四个维度逐项审查：

| 原则 | 说明 |
|------|------|
| **客观性** | 基于证据、中性语言、第三人称视角、不含价值判断 |
| **正式性** | 避免口语化、缩写、俚语，语法规范 |
| **准确性** | 消除冗余与歧义，一句一意 |
| **审慎性** | 论断强度与证据匹配——*可能、似乎、表明、提示* |

## 使用方法

1. 将 `AcademicRegister.md` 放入你的项目或 Claude Code skills 目录。
2. 在让 AI 润色文本时，使用 `@AcademicRegister.md` 引用该技能。
3. AI 将依据四项原则逐项审查你的文本，并标注每处改动及其依据。

## 示例

**修改前（AI生成）：**
> 感知有用性作为一个核心的、关键性的重要中介变量，深刻揭示了其在整个机制中举足轻重的传导角色。

**修改后（学术规范）：**
> 感知有用性在感知AI暴露度与持续使用意愿之间起显著中介作用。
